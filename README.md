# paste-elements-webjar

WebJar packaging for PasteStack Elements UI components.

## Installation

### Maven
```xml
<dependency>
    <groupId>com.pastestack</groupId>
    <artifactId>paste-elements-webjar</artifactId>
    <version>0.1.0</version>
</dependency>
```

### sbt
```scala
libraryDependencies += "com.pastestack" % "paste-elements-webjar" % "0.1.0"
```

## Contents

- `src/js/` — UI JavaScript modules (heroscroll, stickynav, smoothscroll, etc.)
- `src/scss/` — SCSS styles for UI components

## Usage

Assets are available at:
```
/webjars/paste-elements-webjar/0.1.0/src/js/*.js
/webjars/paste-elements-webjar/0.1.0/src/scss/*.scss
```
